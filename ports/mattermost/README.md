# Verdigris for Mattermost

`verdigris-limestone.json` (light) and `verdigris-slate.json` (dark).

## Install

1. Open **Settings → Display → Theme** and choose **Custom Theme**.
2. Click **Copy and paste to share theme colors**, replace the text with the
   contents of one file, and save.

Mattermost has no custom code colours. Code blocks use its built-in `github`
theme in Limestone and `monokai` in Slate.
