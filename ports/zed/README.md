# Verdigris for Zed

`verdigris.json` is a theme family with "Verdigris Limestone" (light) and
"Verdigris Slate" (dark).

## Install

```sh
mkdir -p ~/.config/zed/themes
cp verdigris.json ~/.config/zed/themes/
```

Then in Zed's `settings.json`, follow the system appearance:

```json
{
  "theme": {
    "mode": "system",
    "light": "Verdigris Limestone",
    "dark": "Verdigris Slate"
  }
}
```
