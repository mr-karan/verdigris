# Verdigris for Helix

`verdigris_limestone.toml` (light) and `verdigris_slate.toml` (dark).

## Install

```sh
mkdir -p ~/.config/helix/themes
cp verdigris_*.toml ~/.config/helix/themes/
```

Then in `~/.config/helix/config.toml`:

```toml
theme = "verdigris_slate"
```

Try a flavour first with `:theme verdigris_limestone`.
