# Verdigris for fzf

One snippet per flavour and shell. Each appends `--color` options to
`FZF_DEFAULT_OPTS`. Needs fzf 0.36 or later.

## Install

bash or zsh, in `~/.bashrc` or `~/.zshrc`:

```sh
source /path/to/verdigris/ports/fzf/verdigris-slate.sh
```

fish, in `~/.config/fish/config.fish`:

```fish
source /path/to/verdigris/ports/fzf/verdigris-slate.fish
```

Use the `limestone` files for the light flavour.
